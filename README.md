# OpenClaw (personal assistant)

This is the home page for **OpenClaw**, a private, self-hosted AI assistant that runs on its owner's own computer.

The Google OAuth app called "OpenClaw" exists so this assistant can read and organise its owner's own Gmail, read their Google Calendar, and read their Nest thermostat, all on the owner's behalf and with their consent. It is a single-user, personal-use app. It is not offered to the public and it is not a commercial product.
